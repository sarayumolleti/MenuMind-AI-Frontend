# MenuMind AI — Frontend Web Application

The interactive React frontend for MenuMind AI, crafted with a warm restaurant theme (Cream, Dark Roast Brown, and Forest Green accents).

---

## 🚀 Screens & Features
- **Customer Portal (`/menu`):** Browse digital menu, Veg/Non-Veg filter, add to cart, and submit real-time reviews with ratings.
- **Staff Counter Billing POS (`/pos`):** Fast counter checkout, bill calculations, and receipt printing.
- **Manager Dashboard (`/dashboard`):** Real-time sales analytics, online vs. counter order distribution, and AI BCG Menu Engineering matrix.
- **Menu Management (`/menu-manager`):** Add, edit, soft-delete items, and toggle live item availability ("Out of Stock").
- **Customer Feedback & AI (`/feedbacks`):** Customer sentiment analysis, dish ratings, recurring complaints, and actionable suggestions.
- **Sales & Bills History (`/sales`):** Detailed bills breakdown with order source and payment methods.

---

## 🛠️ Tech Stack
- **Framework:** React 18
- **Build Tool:** Vite
- **Styling:** CSS variables (Cream & Brown Theme)
- **Networking:** Axios with JWT Interceptors
- **Charts:** Recharts

---

## ⚙️ Local Setup

1. Install dependencies:
   ```bash
   npm install
   ```
2. Start development server:
   ```bash
   npm run dev
   ```
3. Build for production:
   ```bash
   npm run build
   ```

Runs locally on `http://localhost:5173`.
